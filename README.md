A faster drop-in for makefun-site 1.0.0: the same answers on every case, built with single-pass scanning, a range-based inline renderer, compiled templates and a cached slug rule instead of per-character and per-line regular expressions. About 3.4x faster than the house baseline on the practice set (3/3 cases byte-identical).

## Run it

```sh
node main.ts
```
